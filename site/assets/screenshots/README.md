# Capturas reais do YugenYumi Launcher

Estas imagens foram fornecidas pelo desenvolvedor e mostram a aparência do **Launcher 9.0.0-dev**. Elas são utilizadas no site do projeto **9.1.0-dev** apenas como referência visual real e têm legenda de origem.

São 15 telas: Início, Módulos, Servidores, Instalações, Cosméticos, Perfis, Screenshots, Contas, Diagnóstico e seis abas de Configurações (Geral, Jogo, Java, Runtime, Compatibilidade, Developer).

Os arquivos .webp mantêm resolução de 1919 px de largura. Os arquivos -thumb.webp são versões reduzidas para a galeria. Os screenshots não foram inventados nem recriados.

Para substituir por capturas de builds futuras, altere também `site-config.js`, textos de versão no HTML e arquivos correspondentes. As imagens recebidas originalmente estavam em PNG, não ficam duplicadas no ZIP público para evitar tamanho desnecessário.

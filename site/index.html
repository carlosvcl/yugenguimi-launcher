PRECISA SABER?

Perguntas frequentes.

Algumas respostas para você entender o projeto antes de instalar.

O YugenYumi já é uma versão final?

Não. A versão 16.6.1-dev é de desenvolvimento. Algumas funções ainda estão sendo implementadas, corrigidas ou validadas no Minecraft real.

Preciso instalar o Java manualmente?

O Launcher foi projetado para preparar o Java 8 de 64 bits e os arquivos necessários. Na primeira inicialização, é necessário acesso à internet para obter dependências que ainda não estão no cache.

Precisa de Forge ou OptiFine?

O Client utiliza sua própria arquitetura para o Minecraft 1.8.9 e não exige Forge para os recursos integrados. A integração com OptiFine não deve ser presumida como ativa nas builds atuais.

Por que o Windows pode mostrar um aviso ao instalar?

Os instaladores beta ainda não possuem assinatura digital de publicação. Por isso, o Windows pode apresentar alertas. Baixe apenas de uma fonte confiável e confirme os arquivos/checksums divulgados junto à versão.

Quais recursos ainda estão em desenvolvimento?

Perspective, Motion Blur, Wings e Preview 3D ainda precisam de melhorias e validação na 16.6.1-dev. Block Overlay, Armor Status, Item Status e outros módulos foram aprovados nos testes Windows anteriores.

O YugenYumi é um projeto oficial do Minecraft?

Não. YugenYumi é um projeto independente, sem afiliação ou endosso da Mojang Studios ou da Microsoft.
